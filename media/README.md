# Cloak & Candle — media pack

Everything you need to write about, sell or show Cloak & Candle.

| folder | what's in it |
|---|---|
| `Cloak-and-Candle-Brand-Guidelines.pdf` | the mark, lockups, clear space, colour, type, voice — read this first |
| `logos/` | the mark, the wordmark, horizontal and stacked lockups, each in rose-gold, rose, ivory, ink, black and white — SVG (outlined, no fonts needed) and transparent PNG (2400 px) |
| `screenshots/` | the TV at 1920 × 1080 (JPEG) and the host phone at 1170 × 2532 (PNG), from a real game |
| `social/` | link preview (1200 × 630), square post (1080 × 1080), story (1080 × 1920) |
| `palette/` | swatch image, CSS variables, JSON and a GIMP/Inkscape palette |
| `copy/press-kit.md` | name, taglines, descriptions (one line, short, long), key facts, feature bullets, boilerplate |
| fonts | not stored here: `python3 tools/marketing-pack.py` builds the full marketing pack (fonts with their licence, the game guide, data sheets and everything in this folder) into `dist/Cloak-and-Candle-Marketing-Pack.zip` |

Rose-gold on dark plum is the hero combination. Use ink on light grounds. Please don't recolour, stretch or retype the logo, and don't pair Cloak & Candle with the name, logo or imagery of any TV programme.

Replace the `[name] · [email] · [domain]` placeholders in `copy/press-kit.md` before sending.
