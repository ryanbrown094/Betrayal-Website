# Fonts

| role | family | used for | licence |
|---|---|---|---|
| display | **Grenze Gotisch** (variable weight) | the wordmark style, titles, names on the TV | SIL Open Font License 1.1 |
| book | **IM Fell DW Pica** (regular and italic) | long text on the TV, the voice of the game | SIL Open Font License 1.1 |
| interface | **Alegreya Sans** (400, 500, 700) and **Alegreya Sans SC** (500, 700) | labels, captions, the website | SIL Open Font License 1.1 |

`web/` holds the exact `.woff2` files the game and site use (Latin and Latin Extended subsets). For design tools (Figma, Canva, InDesign) install the full families from Google Fonts: search each name above. All four are free for commercial use, including in print, video and ads, under the SIL Open Font License (`OFL.txt`). The logo files in `02-brand/logos/` are outlined, so they don't need the fonts installed.
